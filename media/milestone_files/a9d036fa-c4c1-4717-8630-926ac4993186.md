# Change KIGate / v1.0.0.0 (RC1)

## Risiko Risikoklasse: Mittel
Die Risikoklasse "Mittel" wurde gewählt, da die implementierten Änderungen sowohl neue Funktionalitäten als auch kritische Bugfixes umfassen, die wesentliche Systemkomponenten betreffen. Die Einführung von Features wie dem Redis-Cache und die Behebung von API-Konfigurationsfehlern sind entscheidend, um die Systemstabilität und -sicherheit zu gewährleisten. Diese Änderungen erfordern eine genaue Überwachung, um unerwartete Auswirkungen zu minimieren, jedoch wurden alle Maßnahmen zur Risikominderung getroffen.

## Zusammenfassung
Dieses Release von KIGate, Version 1.0.0.0 (RC1), umfasst eine Reihe bedeutender Neuerungen und Verbesserungen. Zu den wesentlichen Neuerungen gehören die Implementierung von Jobstatistiken, die Inline-Preisbearbeitung und die Erweiterung von Jobs und ProviderModels. Zusätzlich wurden mehrere kritische Bugs behoben, darunter Probleme mit API-Konfigurationen und Endlosschleifen bei Ollama-Anfragen. Die neuen Features und Bugfixes tragen dazu bei, die Benutzerfreundlichkeit und Stabilität des Systems zu erhöhen und die Nutzungseffizienz zu verbessern.

## Änderungen

**Job Statistics**
Eine Statistikfunktion zur Auswertung des Nutzungsverhaltens wurde integriert, die Daten auf täglicher, wöchentlicher und monatlicher Basis erhebt.

**Inline-Preisbearbeitung mit automatischer Speicherung in Provider-Modellen**
Es wurde eine Funktion hinzugefügt, die eine Inline-Bearbeitung von Preisen in Provider-Modellen direkt in der Detailansicht ermöglicht.

**Fehlende UI-Integration bei ProviderModels Preise / 1 Mio. Token**
Die Benutzeroberfläche für Provider wurde angepasst, um eine vollständige Detailansicht mit allen CRUD-Operationen zu ermöglichen.

**Erweiterung Jobs und ProviderModels**
Die Jobs wurden um die Erfassung von Output-Token erweitert, um eine vollständige Token-Verfolgung zu ermöglichen.

**Entwicklung einer verbesserten Klonfunktion für Agenten**
Agenten können nun sowohl aus der Listen- als auch aus der Detailansicht heraus geklont werden, unter Beibehaltung aller Datenwerte.

**Erweiterung ListView "Jobs"**
Die ListView für Jobs wurde um Filtermöglichkeiten und eine Bereinigungsfunktion für ältere Jobs erweitert.

**Anfragen an Ollama werden scheinbar in einer Endlosschleife durchgeführt**
Ein Bug wurde behoben, der Anfragen an Ollama in eine Endlosschleife versetzte.

**Ollama API URL is not configured**
Ein Konfigurationsfehler bei der Ollama API URL wurde behoben.

**controller not available: No module named 'ollama'**
Ein Modul-Ladefehler für Ollama wurde behoben.

**Feature: Redis-Cache für KIGate Agenten (AOI)**
Ein Redis-basierter Caching-Mechanismus wurde für den `/agent/execute`-Endpoint eingeführt, um die Leistung bei wiederholten Anfragen zu verbessern.

**Ollama lokal ist nicht verwendbar**
Die Unterstützung für Ollama wurde korrekt integriert.

**Provider und Model bei Agenten**
Ein Problem mit der Angabe von Providern und Modellen bei Agenten wurde behoben.

**gemini Api key ist nicht im env!!!**
Mehrere Konfigurationsprobleme mit dem Gemini API Key wurden behoben.

**Gemini API key is not configured**
Der API Key für Gemini wurde richtig konfiguriert und aus den Umgebungsvariablen entfernt.

**WARNING - GEMINI_API_KEY not found**
Die Speicherung des API Keys wurde angepasst, sodass er in der Entität Provider verwaltet wird.

**Unsupported AI provider: Google Gemini**
Das Problem mit der Nutzung von Google Gemini wurde behoben.
