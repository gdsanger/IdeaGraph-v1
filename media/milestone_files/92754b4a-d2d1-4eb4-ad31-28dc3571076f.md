# Change IdeaGraph v1.0 / V1.0.1

## Risiko Risikoklasse: Mittel
Die Risikobewertung für das Update auf V1.0.1 von IdeaGraph wurde als "Mittel" eingestuft. Die Begründung hierfür liegt in der Vielzahl der behobenen Bugs, die auf potenzielle Sicherheitslücken und Systeminstabilitäten hinweisen könnten. Zudem wurden einige neue Features implementiert, die eine umfassende Integration externer APIs beinhalten (z.B. Sentry, GitHub, und Microsoft Graph API). Diese Integration könnte potenzielle Schwachstellen für die Datensicherheit darstellen, wenn nicht ordnungsgemäß konfiguriert.

## Zusammenfassung
Das Update V1.0.1 von IdeaGraph bringt eine Vielzahl von Verbesserungen und Bugfixes mit sich. Es wurden wichtige Integrationen mit Sentry und GitHub optimiert, um die Synchronisation von Aufgaben und Fehlerberichten zu verbessern. Neue Funktionalitäten wie die Integration der Microsoft Graph API und die Möglichkeit zur automatischen Synchronisation von Dokumentationen aus GitHub erweitern die Funktionalität der Plattform erheblich. Zahlreiche bestehende Fehler wurden behoben, was die Stabilität und Benutzbarkeit der Plattform verbessert.

## Änderungen

### Bugfixes
- **Could not parse DSN:** Fehler bei der DSN-Analyse wurde behoben.
- **Fetch Sentry Errors not working:** Behebung des Problems mit der Sentry-Fehlerabfrage.
- **Invalid Sentry DSN hostname:** Fehlerhafte Sentry DSN-Konfiguration wurde korrigiert.
- **GitHub API error 404:** Problem bei der GitHub API-Synchronisation wurde gelöst.
- **OperationalError: no such column:** Problem mit fehlender Spalte in der Datenbank behoben.
- **Mail_process Infinity Loop:** Endlosschleife beim E-Mail-Versand wurde beseitigt.
- **Embedding Support Chat issues:** Probleme mit dem eingebetteten Support-Chat wurden behoben.
- **Various UI-related bugs:** Probleme mit UI-Komponenten und Fehlermeldungen wurden adressiert.

### Neue Features
- **Sentry Integration bei den Items:** Verbesserung der UI-Integration für Sentry.
- **Neue Task-Indikatoren:** Einführung eines Indikators für neue Aufgaben über alle Items.
- **Verbesserte GitHub-Integration:** Manuelle Synchronisation von GitHub-Dokumentationen auf Item-Ebene.
- **UI-Komponente für Support-Chat:** Anpassung und Neudesign des eingebetteten Support-Chats.
- **Integration der Microsoft Graph API:** Unterstützung für E-Mail-Versand über die Microsoft Graph API.
- **Erweiterung der Floating Action Dock:** Einheitliche Integration von Graph, Files und globaler Suche.

### Verbesserungen
- **Optimierung der Sidebar-Funktionen:** Verbesserung der Sidebar zur besseren Nachverfolgbarkeit von Aktivitäten.
- **Verbesserte Task-/GitHub-Integration:** Verbesserungen der Kanban-Übersicht und der Nachvollziehbarkeit des Entwicklungsflusses.
- **Optimierung der CSS-Stylesheets:** Zentralisierung und Optimierung von CSS-Stylesheets zur Reduzierung von Redundanzen.

### Sonstige Anpassungen
- **Erweiterung der Kommentarfunktion:** Integration von Typen wie Note und Mail und Verbesserung der Mailversandfunktionalität.
- **Verbesserte Taskfunktionen:** Einführung von Taskvorlagen und der Funktion zur Klonung von Tasks.

Dieses Update bringt bedeutende Verbesserungen und behebt zahlreiche Bugs, was die Effizienz und Stabilität von IdeaGraph erhöht. Die neuen Features bieten eine bessere Integration und Funktionalität, während die Bugfixes die Zuverlässigkeit des Systems stärken.
